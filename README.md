### 🧬 Currently

Co-founding **[GeMorph](https://github.com/GeMorph)** — we reconstruct 3D facial models directly from DNA, for forensic and law-enforcement use.

<br>

### 🔬 things I've built

| Project | What it does |
|---|---|
| **Faces from DNA** | A pipeline predicting 3D facial structure directly from genomic data — AE vs. DiT architectures, benchmarked head to head. Won SEECS Open House 2025. |
| **Ancestry from DNA** | Local ancestry inference built on SALAI-Net, pushed for finer resolution and accuracy than off-the-shelf baselines. |
| **LLM Router** | A capability-aware routing system — profiles each candidate model, then routes each query to whichever one is actually good at it. |
| **PPI + Generative Genomics** | Autoencoders and diffusion models applied to genomics data for personalized-medicine pipelines, plus LLM fine-tuning for genomics-specific tasks. |
